# Миграции БД

## Что это

Миграции — это SQL-файлы, которые **аккуратно изменяют схему БД** без потери данных.

Раньше ты удалял `bot.db` при каждом изменении схемы. Теперь — просто создаёшь новую миграцию.

## Как это работает

1. При старте бот проверяет таблицу `schema_version` — там записано, какие миграции применены.
2. Находит новые файлы в `migrations/`.
3. Применяет их **по порядку**.
4. Записывает версию в `schema_version`.

## Как добавить новую миграцию

1. Создай файл `NNN_описание.sql`, где `NNN` — три цифры (номер больше последнего).
2. Напиши SQL-команды. **Без транзакций** — обёртка сама.
3. Перезапусти бота — миграция применится.

## Формат имени

`NNN_описание.sql` — где NNN — три цифры с ведущими нулями.

Примеры:
- `001_initial.sql`
- `002_add_tests_paused.sql`
- `003_create_subscriptions.sql`
